Serveur injoignable

Le serveur ne répond pas. Vérifiez que le NAS est allumé et que ce PC est connecté au même réseau.

Après une mise à jour, le serveur redémarre en une minute environ.

Connexion à votre serveur

Indiquez l'adresse de votre serveur DARTS EVOLUTION (NAS) : celle que vous tapez dans le navigateur pour ouvrir l'application. Elle est aussi affichée dans Paramètres → « Application sur téléphone », sous le QR code.

    Joueurs, parties, statistiques et carrière restent enregistrés sur le serveur : ce sont les mêmes sur le PC, le téléphone et la tablette.
